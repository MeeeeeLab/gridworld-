# GRID//RIFT：双人第一人称竞速对战 Demo

一个本机 TCP 服务端、两个独立 Java 客户端、两个 800×640 窗口。两名玩家从 25×25 迷宫的不同角落出发，争夺中央绿色信标。地图包含环路、分岔、死胡同，以及带掩体的中央交战区。

## 启动

需要 **Java 21 JDK**（源码运行）以及可用的桌面 / OpenGL 3.3 环境。首次运行 Gradle 会下载依赖。

- Windows：在 `GridWorld3D` 目录双击 `run-demo.bat`。
- macOS / Linux：进入 `GridWorld3D`，运行 `bash run-demo.sh`。
- 也可执行 `bash gradlew :desktop:raceDemo`；推荐启动脚本，它将构建产物放到 Gradle 用户目录，避免覆盖仓库已提交的旧 class / jar。
- 不需要账号、令牌、额外服务器或手动填写端口。端口自动分配，**只监听 127.0.0.1**。
- 退出任一窗口 / 按 Esc 结束整场；重新运行脚本开始新的一局。窗口窄屏重叠时可自行拖动。

如果拿到的是预编译 ZIP，解压后运行包里的 `run-demo.bat` 或 `bash run-demo.sh`，只需 Java 21 运行时，不需要 Gradle。默认关闭音频，因此无声卡也能运行。

## 两种完全不同的操作和攻击

| | 玩家 1：SCOUT 侦察兵（青色） | 玩家 2：SIEGE 重装车（橙色） |
|---|---|---|
| 移动方式 | W/S 前后，A/D 横移；Q/E 转向 | ↑/↓ 前进倒车；←/→ 原地转向，不能横移 |
| 移动速度 | 每 0.20 秒一格 | 每 0.35 秒一格 |
| 攻击 | 空格：周围 EMP 脉冲，无需瞄准 | Enter：沿炮口方向发射直线轨道炮，必须对准 |
| 射程 | 半径约 2.4 格 | 前方 8 格 |
| 命中效果 | 失速 1 秒，小地图干扰 2 秒，不击退 | 停车 1.5 秒，向射击方向击退 1 格；有墙时不穿墙 |
| 冷却 | 2.75 秒 | 3.25 秒 |
| 自动导航 | N，一局一次 | M，一局一次 |

两种攻击都会被墙挡住。失速结束后另有 1 秒保护，避免被连续控制。攻击用于争夺路线和拖延对手，没有生命值 / 死亡 / 复活机制。

**同一台电脑共用键盘**：点击任一游戏窗口后，两套按键都生效，可同时控制双方；没有焦点的窗口仍持续运行和同步。切换窗口会释放按键，防止一直移动。不要将没有焦点的窗口最小化。部分键盘同时按很多键会有硬件键位冲突。

## 视野、地图与导航规则

- 摄像机位于角色眼睛高度，跟随格子移动和转向平滑过渡；没有俯视全地图模式。
- 小地图初始几乎全黑，只揭示附近约 3 格且未被墙挡住的区域；探索记录各自保存。
- 已探索区域长期保留；对手标记仅在当前近距离且无遮挡时出现，不会追踪远处对手。
- 未知地形、隐藏对手坐标、导航路径均不发送给客户端。
- 被 EMP 命中时小地图暂时离线，恢复后保留原探索记录。
- 自动导航启动后**连续带玩家走到终点**，用掉一次机会；期间不能手动改变路线，但仍能攻击。被打中只会暂停，恢复后继续；被击退会重新规划，不补充机会。
- 导航复用仓库根目录的 `SearchController` / `PathFinder` / `GridMap` / `AgentMove`，使用距离启发式选择方向和深度优先回溯。没有替换成另一套最短路算法，**不保证最短路径**。
- Demo 的导航器在服务端读取完整迷宫求可行路径；玩家和客户端只获得逐步探索的信息。若下一版要求算法也只能看局部地图，需要改为边探索边规划。
- 先抵达绿色信标者获胜。完成后冻结双方状态；被对手击退到终点也算获胜。

## 代码结构与验证

`algorithm` Gradle 模块直接编译根目录六个算法源文件；为算法补充任意起点构造函数和路径导出，保留原构造函数。`RaceWorld` 负责地图、移动、攻击和胜负，`RaceServer` 以 20 Hz 同步状态；`RaceGame` 负责第一人称画面、小地图及共享键盘。原来的单人 3D 入口保留。

```bash
# 无需图形界面的功能检查（含真实双客户端 TCP 通信）
bash gradlew -I demo.init.gradle :desktop:raceCheck

# 两个真实窗口的渲染、第一人称、探索地图和网络导航检查
# 输出目录必须是本次新建的空目录；保存两张 PNG 和两个 .pass 文件。
bash run-demo.sh --args="--visual-check /tmp/gridworld-race-check-new"

# 打包含依赖的试玩 ZIP；不包含 Java 运行时
bash gradlew -I demo.init.gradle :desktop:raceDemoZip
```

Demo 有意保留的范围：固定地图种子、不做联网账号和远程连接、不支持断线重连、无声音资源。双方暂时可以擦身通过，不做玩家之间的实体阻挡；墙壁有碰撞，攻击有遮挡。两个角色是原型玩法，尚未做竞技平衡。Windows / macOS 提供启动入口，但本次实际验证平台为 Linux + Mesa 软件渲染。
